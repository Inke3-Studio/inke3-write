# Inke3-Write

✨ 基于 inke3 生态构建的轻量级写作辅助与排版工具。

## 📖 项目简介

`inke3-write` 是万维银客城（Inke3）生态中的独立写作辅助模块，旨在为创作者提供更舒适的排版、字数统计及文本处理体验。

## 🛠️ 技术栈

- **语言**：TypeScript / JavaScript[cite: 1]
- **框架**：React / Vite
- **工具链**：Node.js, ESLint

## 🚀 快速开始

如果你想在本地运行或参考本项目：

1. 克隆仓库：
   ```bash
   git clone [https://github.com/Inke3-Studio/inke3-write.git](https://github.com/Inke3-Studio/inke3-write.git)

2. 安装依赖
   ```bash
   npm install
4. 启动开发服务器
   ```bash
   npm run dev
